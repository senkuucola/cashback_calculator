# 💰 Калькулятор кэшбэка по банковской карте

Проект для учебной практики (УП.02). Разработан на Python 3.8+.

## 📌 Назначение

Приложение помогает рассчитать сумму кэшбэка за месяц на основе:
- покупок в разных категориях
- повышенного кэшбэка (акции, бонусы)
- месячного лимита кэшбэка

## 🚀 Функциональность

- Ввод покупок (категория + сумма)
- Настройка повышенного кэшбэка по категориям
- Учёт месячного лимита
- Логирование всех расчётов в файл `cashback.log`
- **Математическая модель** для выбора оптимальной банковской карты
- **Графический интерфейс** (Tkinter)

## 🧮 Математическая модель

**Целевая функция:** максимизация кэшбэка
C = Σ (x_i × p_i / 100) → max

**Ограничение:** C ≤ L (лимит карты)

Модель сравнивает 4 банковские карты с разными ставками и выбирает оптимальную.

## 🖥️ ЗАПУСК ПРОГРАММЫ

### Графическая версия 

Самый удобный способ. Откроется красивое окно с вкладками.

```bash
python run_tkinter.py
```
Что делать после запуска:

Откроется окно "Калькулятор кэшбэка по банковской карте"

Во вкладке "📋 Покупки" добавляйте покупки:

Введите категорию (например: супермаркеты)

Введите сумму (например: 5000)

Нажмите "➕ Добавить"

Во вкладке "🎁 Бонусы" добавьте повышенный кэшбэк:

Введите категорию (например: транспорт)

Введите доп. процент (например: 2)

Нажмите "🎁 Добавить бонус"

Установите месячный лимит (например: 3000)

Нажмите "🧮 РАССЧИТАТЬ КЭШБЭК"

Результат появится во вкладках "💰 Результат" и "📊 Сравнение карт"
