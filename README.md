💳 Система расчёта кэшбэка по банковской карте
📋 Техническое задание
1. Назначение программы
Программа предназначена для автоматического расчёта суммы кэшбэка по банковской карте за месяц.

Ключевые возможности:

Расчёт кэшбэка по 5 категориям покупок
Учёт месячного лимита кэшбэка
Применение акционных повышенных ставок
Сравнение с альтернативными тарифами
Логирование всех расчётов
2. Входные данные
Пользователь вводит следующие данные:

Параметр	Тип	Диапазон	Описание
Расходы в супермаркетах	float	≥ 0 руб.	Сумма трат в супермаркетах
Расходы на такси	float	≥ 0 руб.	Сумма трат на такси
Расходы в кафе	float	≥ 0 руб.	Сумма трат в кафе и ресторанах
Расходы в аптеках	float	≥ 0 руб.	Сумма трат в аптеках
Прочие расходы	float	≥ 0 руб.	Сумма остальных покупок
Ставка кэшбэка (супермаркеты)	float	0-30%	Процент возврата
Ставка кэшбэка (такси)	float	0-30%	Процент возврата
Ставка кэшбэка (кафе)	float	0-30%	Процент возврата
Ставка кэшбэка (аптеки)	float	0-30%	Процент возврата
Ставка кэшбэка (прочее)	float	0-30%	Процент возврата
Лимит кэшбэка за месяц	float	≥ 0 руб.	Максимальная сумма возврата
Акционная категория (опционально)	str	-	Категория с повышенным кэшбэком
Акционный процент (опционально)	float	0-30%	Повышенная ставка

6. Математическая модель
6.1. Базовый расчёт
cashback_i = expense_i × (rate_i / 100) total = Σ cashback_i result = min(total, limit) exceeded = max(0, total - limit)

6.2. Сравнение тарифов
F_A = min(Σ (expense_i × rate_A_i / 100), limit_A) F_B = min(Σ (expense_i × rate_B_i / 100), limit_B) Рекомендация = A если F_A > F_B, иначе B

6.3. Переменные
expense_i — расходы по категории i (руб)
rate_i — ставка кэшбэка по категории i (%)
limit — месячный лимит кэшбэка (руб)
